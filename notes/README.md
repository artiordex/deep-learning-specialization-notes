# Notes

This directory contains course notes and theoretical explanations for the Deep Learning Specialization.

## Structure

- `course1-neural-networks/` - Neural Networks and Deep Learning
- `course2-optimization/` - Improving Deep Neural Networks: Hyperparameter Tuning, Regularization and Optimization
- `course3-ml-projects/` - Structuring Machine Learning Projects
- `course4-cnns/` - Convolutional Neural Networks
- `course5-sequences/` - Sequence Models

## Format

Notes are organized in Markdown format for easy reading and version control. Each course has its own subdirectory containing:
- Lecture summaries
- Key concepts and formulas
- Visual diagrams (when applicable)
- Reference materials

## Usage

Browse the notes by course and topic. Use the table of contents in each file to quickly navigate to specific concepts.
